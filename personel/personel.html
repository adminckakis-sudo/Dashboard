KUPT Crew KA

Mengelola program kerja, kinerja, keselamatan, dan pengembangan kompetensi awak kereta api.

Penyelia Instruktur

Membina, melatih, dan mengawasi operasional masinis serta mengevaluasi kinerjanya secara berkala.

Penyelia Dinas

Mengatur dinasan awak kereta api, input sistem perencanaan, asesmen pradinas, serta memantau operasi dan langsiran.

Masinis Madya & Muda

Mengoperasikan kereta api dan langsir, memimpin perjalanan, memastikan keselamatan operasional, serta membina asisten masinis.

Masinis Pertama

Mematuhi perintah masinis, mengelola pencatatan Lapka dan dokumen perjalanan, memeriksa indikator kabin, serta membantu penanganan gangguan.
